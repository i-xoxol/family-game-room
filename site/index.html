WHY I BUILT THIS

Made for my son.
Shared for builders.

I wanted small, personal games that would run on the iPad we already had. Each project grew out of watching a child play: where a prompt was confusing, where a finger missed, or where a picture distracted from the words.

I use AI coding tools to develop and refine these projects. The useful work is in the details: instructional choices, prepared assets, privacy boundaries and testing the whole interaction.

The static demos save progress only in your browser. Robi’s paid conversation requires a separate parent-configured server. Public source excludes family profiles, credentials and child recordings.
