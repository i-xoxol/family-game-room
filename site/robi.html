Робі

A little robot for big questions.

A Ukrainian-speaking robot listens, gestures and explores one thing at a time. Prepared games work without a model; parent-enabled conversation adds realtime voice, selected-source search and weather.

Open Robi’s project page ↗Browse the source ↗

Inside the experience

  • Hold-to-talk turns with an animated SVG robot and matching visuals.
  • Counting, colors, shapes and riddles have prepared Ukrainian narration.
  • Optional paid voice, web search and memory run on a password-protected server.
  • The public collection pins the separate Robi source repository as a Git submodule.

Built with purpose

The public page is a project overview. It has no connection to a family service. A parent must configure their own deployment, provider settings and voice eligibility.

See the game README for setup, checks and limitations.
