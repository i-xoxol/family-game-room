Finger flight · friendly rescues

Super Eric

One little hero. A whole sky to help.

Fly a tiny superhero through soft skies, gather lights and help friends. A custom Canvas engine sits beneath a React interface, keeping the world lively and the controls simple.

Play the game ↗Browse the source ↗

Inside the experience

  • Touch-driven flight and rescue goals with gentle visual feedback.
  • Canvas 2D engine with React controls, local progress and generated browser audio.
  • Complete TanStack Start source is included, with build and deployment notes.
  • Originally created with Grok App Builder; its platform marks and scaffold remain credited.

Built with purpose

This game uses a server-rendered framework. GitHub Pages hosts this overview; the play link opens the existing public game. The other three demos run directly on Pages.

See the game README for setup, checks and limitations.
