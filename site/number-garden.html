Counting · playful practice

Number Garden

A little math. A whole lot of magic.

Count, match, compare and build little numbers with garden friends. Short activities, spoken prompts and flowers earned through play give a young learner a reason to try again.

Play the game ↗Browse the source ↗

Inside the experience

  • Six small activity types with visual objects and large answer controls.
  • 83 prepared narration clips, bundled fonts and original SVG garden art.
  • Progress stays in the current browser; there are no accounts, analytics or runtime AI calls.
  • Game logic and audio manifests have automated regression tests.

Built with purpose

Made for touch in landscape. Prepared narration supports a child who cannot yet read all the instructions.

See the game README for setup, checks and limitations.
